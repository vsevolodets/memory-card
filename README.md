# Памятка водителя — Таксимания (лендинг)

Одностраничный mobile-first лендинг для водителей «Таксимании». Водитель попадает
на него по QR-коду из печатной памятки и получает: выбор своей колонны и контакты
менеджеров, чек-лист перед выходом на линию, правила аренды и выплат, как больше
зарабатывать, штрафы, еженедельный осмотр с картой, правила возврата автомобиля,
FAQ с поиском и форму обращения без backend.

Источник всех данных (телефоны, графики, штрафы, правила) — 4 финальные
DOCX-памятки. Все данные лендинга дублируют их без изменений; исправлена только
опечатка «коэфициенты» → «коэффициенты» (по прямому указанию в ТЗ).

## Структура проекта

```text
index.html   — разметка страницы
styles.css   — все стили (mobile-first, брейкпоинты 768/1024/1440)
script.js    — вся интерактивность (колонны, FAQ, карта, форма и т.д.)
data.js      — ЕДИНСТВЕННЫЙ файл с содержимым, который нужно редактировать
assets/      — логотип
README.md    — этот файл
```

Правки контента (телефон, штраф, адрес и т.д.) вносятся только в `data.js`.
`index.html` / `styles.css` / `script.js` менять не нужно для обычных
редакторских правок.

## Где что искать в data.js

| Что редактировать | Где в data.js |
|---|---|
| Менеджеры и телефоны | `columns` → нужная колонна → `managers` |
| Ссылки MAX | `managers[i].maxUrl` (пусто — кнопка скрыта) |
| Личный Telegram менеджера | `managers[i].telegramUrl` (пусто — кнопка скрыта) |
| Общий Telegram-бот | `links.telegramBot` |
| FAQ | `faq` (массив вопрос/ответ/категория) и `faqCategories` |
| Данные еженедельного осмотра, координаты | `inspection` |
| Штрафы | `fines`, `finesNote`, `finesWarning` |
| Чек-лист перед выходом | `checklist`, `checklistWarning` |
| Аренда и выплаты | `payments` |
| Как больше зарабатывать | `earnings` |
| Правила возврата авто | `returnRules` |
| Обработчик формы обращения | `script.js`, функция `initContactForm()` (см. ниже) |

### Как поменять телефон менеджера

Открыть `data.js`, найти нужного менеджера внутри `columns`, изменить
`phone` (формат `+7XXXXXXXXXX`, используется в `tel:`-ссылке) и
`phoneDisplay` (то, что видит водитель, например `+7 977 823-03-00`).

### Как добавить ссылку MAX

В объекте нужного менеджера заполнить `maxUrl: "https://max.ru/u/..."`.
Пока поле пустое — кнопка «Написать в MAX» на сайте не показывается.
Аналогично для `telegramUrl` (личная ссылка на менеджера в Telegram, не бот).

### Как отредактировать FAQ

Добавить/изменить объект в массиве `faq`:

```javascript
{
  category: "money",       // один из id в faqCategories
  question: "Текст вопроса",
  answer: "Текст ответа",
}
```

### Как изменить координаты осмотра

Поменять `inspection.latitude`, `inspection.longitude` и `inspection.coordinates`
(строка для отображения и копирования). Ссылки на Яндекс Карты и маршрут
строятся в `script.js` автоматически из этих же значений — трогать их не нужно.

### Обработчик формы обращения

Формы сейчас работают без backend (см. ТЗ, раздел 14): при отправке текст
обращения собирается, копируется в буфер обмена, и водителю предлагается
открыть Telegram-бот и вставить текст. Вся логика — в `script.js`,
функция `initContactForm()`. Когда появится реальный backend (Google Forms,
Apps Script, Telegram Bot API или свой сервер), нужно заменить в этой функции
блок `copyToClipboard(text).then(...)` на реальный запрос отправки.

## Публикация

Проект полностью статический (HTML/CSS/JS, без сборки и без сервера). Чтобы
опубликовать:

1. Загрузить всю папку (`index.html`, `styles.css`, `script.js`, `data.js`,
   `assets/`) на любой статический хостинг — например GitHub Pages, Netlify,
   Vercel, Cloudflare Pages, или обычный веб-сервер (nginx/Apache) компании.
2. Никаких переменных окружения или ключей API не требуется — карта работает
   через бесплатный OpenStreetMap (без API-ключа), кнопки маршрута ведут на
   Яндекс Карты по прямой ссылке.
3. Указать полученный адрес (домен) в QR-коде, который печатается на памятке.
4. Открыть сайт с телефона и проверить: выбор колонны, звонок менеджеру,
   карту, FAQ.

Открыть локально для проверки можно просто двойным кликом по `index.html`
(браузер откроет его как `file://`) — весь функционал, кроме самой карты,
работает и без сервера. Карта (OpenStreetMap) в некоторых браузерах в режиме
`file://` может не подгружаться из соображений безопасности браузера — в этом
случае достаточно поднять любой локальный сервер, например:

```bash
cd taxi-landing
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Карта осмотра

Карта реализована на Leaflet.js + OpenStreetMap (оба подключаются с CDN,
ключ API не нужен). Маркер стоит строго в точке из `data.js`
(`inspection.latitude` / `inspection.longitude`). Если карта не смогла
загрузиться (нет интернета, заблокирован CDN и т.п.), автоматически
показывается текстовый блок-заглушка с адресом и координатами — водитель в
любом случае не останется без информации, где проходит осмотр.

## Что уже проверено

Через автоматизированный тест (headless-браузер) проверено:

- ширины 320 / 375 / 390 / 430 / 768 / 1024 / 1440 px — горизонтальной
  прокрутки нет ни на одной;
- все 4 колонны переключаются и показывают правильное число менеджеров
  (3 / 2 / 2 / 3), карточка «Руководитель» — только в колонне
  Анатолий/Илья;
- корректные `tel:`-ссылки на все номера;
- FAQ: 14 вопросов, поиск, фильтр по категориям, раскрытие ответа, состояние
  «ничего не найдено»;
- 7 строк штрафов, 7 пунктов чек-листа, 6 строк аренды и выплат, 7 пунктов
  «как больше зарабатывать» — все числа совпадают с ТЗ;
- кнопки «Построить маршрут» и «Открыть в Яндекс Картах» формируют корректные
  ссылки с координатами осмотра;
- копирование координат и кнопка «Скопировано»;
- форма обращения формирует текст, копирует его и предлагает открыть
  Telegram-бот;
- клавиатурная навигация (Tab) и фокус;
- отсутствие WhatsApp где-либо в интерфейсе и коде.

Важное ограничение тестовой среды: карта (Leaflet + OpenStreetMap) грузится
с внешнего CDN, а в изолированной песочнице, где готовился лендинг, доступ к
произвольным внешним доменам ограничен политикой безопасности инструмента —
поэтому в скриншотах видна текстовая заглушка вместо самой карты. Сам код
карты рабочий и стандартный (Leaflet — самая распространённая бесплатная
JS-карта, миллионы сайтов используют именно её); при открытии сайта в обычном
браузере с обычным доступом в интернет (в том числе локально или после
публикации) карта загрузится и покажет маркер на нужном адресе. Рекомендуем
дополнительно открыть сайт в обычном браузере и убедиться, что карта
отображается — на случай если хостинг компании блокирует cdnjs.cloudflare.com
или tile.openstreetmap.org.
